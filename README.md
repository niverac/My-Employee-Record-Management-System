# Employee Management System (EMS)

A web-based **Employee Management System (EMS)** developed using Python Flask and MySQL. This application is designed to simplify employee record management and administrative tasks through a centralized and user-friendly web interface.

The project demonstrates practical implementation of backend development, database integration, CRUD operations, and dynamic web interfaces.

## 🚀 Features

- **Employee Management** – Add, view, update, and delete employee records.
- **Department Management** – Organize and manage company departments.
- **Vacation Management** – Manage and track employee vacation records and requests.
- **Dashboard** – Display employee statistics and management summaries.
- **Search & Filtering** – Search and filter records for easier data management.
- **Database Integration** – Store and manage application data using MySQL and SQLAlchemy.
- **Responsive Interface** – User-friendly interface built with Bootstrap.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Navigate to the Project Directory

```bash
cd YOUR-REPOSITORY
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment:

**Windows:**
```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure the Database

- Create a MySQL database.
- Configure your database connection settings.
- Update the application configuration with your database credentials.

### 6. Run the Application

```bash
python app.py
```

Open your browser and navigate to:

```text
http://127.0.0.1:5000
```
